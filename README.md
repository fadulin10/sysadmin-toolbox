---

## 📂 Contenido de la Caja de Herramientas

### 🔍 [1. Log Parser / Text Filtering Tool](./log-parser)

Este es el primer script de mi colección. Se trata de una herramienta en **Python** diseñada para analizar archivos de texto planos de gran tamaño (como archivos de registro o logs de servidores).

*   **Problema que resuelve:** Revisar manualmente logs de miles de líneas es ineficiente.
*   **Funcionalidad:** Filtra el archivo buscando palabras clave críticas (ej: `ERROR`, `FAILED`, `CRITICAL`), guardando los resultados en un archivo nuevo para un diagnóstico rápido.
*   **Habilidades demostradas:** Programación en Python, manejo de archivos (E/S), manipulación de cadenas de texto y automatización de procesos de auditoría.
